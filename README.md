# Store Page Lab

A standalone unofficial store-page mockup. Open `index.html` in a browser, or put it at your static site's root.

Use **Edit page details** to change the sample content. Edits are stored in that browser's local storage, not written back to the HTML file or shared with other visitors. To set permanent defaults for your repository, edit the `defaults` object near the end of `index.html`. You can also replace the screenshot URL list there with your own direct image URLs.

The wishlist button is only a visual demo. This page is not affiliated with Steam.
