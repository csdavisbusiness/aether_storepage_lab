02 / Procedure

How it works

01

Unlock

Enter the access code we sent you. It opens the playtests you’ve joined, on this device.

02

Download once

Unzip the build anywhere and run the game. Keep the folder together.

03

It updates itself

Each start, the game checks for a newer build, fetches it in the background and installs it next launch. Saves and settings stay.

04

Report

Send bugs from inside the game (F1 in Off Record). Your logs go with it, straight to the developers.
